==============================================================
 미팅 요약: 핸드쉐이크 (병원 통신 인프라 구축 업체) 홈페이지 제작
==============================================================
※ 녹취(STT) 오인식이 많아 문맥으로 보정했습니다.
   (컴퓨존/컴피존, 개원 가이드/대원 가이드, 시안/시한, as/에이스 등)
※ 웹노바 측 참석자: 참석자 2(진행/견적 담당), 참석자 6(기획/제작 설명)
   클라이언트: 참석자 1(대표). 그 외 참석자는 잡담/잡음.


--------------------------------------------------------------
1. 클라이언트 배경 (핸드쉐이크)
--------------------------------------------------------------
- 사업: 병원 개원 시 필요한 통신 인프라를 구축해 주는 회사
  (인테리어는 하지 않음)
  · 취급 품목 7개: 통신사, 네트워크, 컴퓨터, 프린트(주변기기),
    보안(CCTV/경비), 가전, 디스플레이(대기명단/광고용 등)
  · 3년간 약 300곳 납품
- 핵심 강점: 신뢰
  · 전문직(병원) 집단이 폐쇄적이라 소개 영업 중심 (보험 영업처럼)
  · 진료 불가 시 당일 A/S, 토요일 근무
    (평일 9~20시, 토요일 9~15시, 일요일/공휴일 휴무. 계약서에 명시)
  · 카톡방으로 개원 전 납품 관리 + 개원 후 사후 관리(CS)
  · 원격으로 증상 확인 가능한 네트워크 장비 사용
    (장비 가격은 비싸지만 A/S 부담을 줄임)
  · 통신/보안/가전 등 여러 업체를 따로 부르면 당일 현장이 뒤죽박죽이
    되는데, 한 업체가 순서대로 세팅해 주는 것이 차별점
- 가격: 견적을 투명하게 공개하는 방식
  · 컴퓨존 부품가 + 용역료 20%
    (실제로는 네트워크 5% 공제로 15%이나 20%로 안내)
- 영업 루트 3가지
  1) 거래처 (인테리어, 프랜차이즈, 개원 컨설팅 업체)
  2) 원장님 소개 / 고객 관리 (3개월 주기)
  3) SNS (최종적으로 가장 강해야 한다고 봄)
- 비전: 업계 점유율 1위 + 미디어 업체화
  · 인스타그램, 홈페이지, 네이버 지도/플레이스, 유튜브, 블로그를
    하나씩 구축 중. 지금은 홈페이지 단계
- 조직: 대표가 영업/마케팅/브랜딩을 직접 담당. 실무자는 현장/관리
  인력이고 마케팅/브랜딩은 외주. 프로젝트 소통 창구는 대표 한 명.
- 대표의 의뢰 방식: 직접 AI로도 만들어 봤으나 세부 해석이 어려워
  전문가에게 맡기기로 함 ("미용사에게 커트 맡기듯" 원하는 스타일을
  정확히 요구하는 방식).


--------------------------------------------------------------
2. 홈페이지의 목적과 타깃
--------------------------------------------------------------
- 1순위 목적: 신뢰도 향상 + 소구점(궁금증/불안)을 미리 해소
  · 미팅 전에 홈페이지로 회사가 하는 일, A/S 체계를 이해시켜
    "소구된 상태로 문의가 들어오게" 하는 것
  · 방문자 수 증가보다 전환율/이해도가 중요
- 타깃
  · 직접 구매하는 원장님
  · 소개를 해 주는 거래처 (인테리어/프랜차이즈/컨설팅 업체)
    -> "이 업체에 소개해도 되겠다"는 믿음을 주는 것도 목적
- 분위기: 신뢰감, 전문적, 편리함, 신속함 / 양지의 느낌
- 컬러: 브랜드 컬러 파랑(네이비)을 기본으로 흰색/하늘색 톤 구성.
  대표가 AI로 통일해 만든 회사소개서/PPT의 색상과 폰트를 기준으로
  통일해 달라고 요청
- 반응형(모바일) 포함 (견적에도 포함됨)


--------------------------------------------------------------
3. 핵심 요구사항 (홈페이지 콘텐츠)
--------------------------------------------------------------
[1) 메인 - 모션 그래픽 (가장 중요)]
- 인스타그램에서 본 레퍼런스처럼, 스크롤/마우스에 따라 스토리가
  흐르는 모션 페이지
- 내용: 상담 -> 견적 -> 계약 -> 품목별 설치 -> 납품 후 사후관리까지
  개원 과정 전체를 "처음부터 끝까지" 보여줌 (대표 표현: 0부터 10까지)
- 표현 방식: 인포그래픽/캐릭터화 (로고를 본뜬 캐릭터 또는 사람,
  AI 이미지, 실사 모두 가능)
- 목적: 단순 기능이 아니라 "회사의 마인드/가치"를 전달
- 웹노바 의견: 기능 구현은 가능하지만 "어떤 장면으로 보여줄지"
  고민이 필요함 -> 필요한 자료를 미팅 후 요청하기로 함
- 메인에는 서비스/차별점 요약 프리뷰, 협력업체 로고,
  문의하기(맨 아래)도 포함

[2) 회사 소개]
- 철학/가치, 핵심 메시지 (신뢰와 성장, 신속한 A/S, 편리한 납품)
- 강점: 당일 A/S, CS 관리방 운영

[3) 서비스 (차별성 + 절차)]
- 품목별(통신/보안/가전 등) 차별점과 절차(개통 절차 등) 정리
- 가격은 공개하지 않음
  · 상품이 7개 품목으로 복잡해 대/중/소로 나눌 수 없고,
    견적서도 복잡해서 상담 단계에서 안내하는 것이 낫다고 결정
  · 과별(진료과별) 맞춤 제안이 가능하다는 점을 강조
- 별도의 "개원 가이드" 페이지는 만들지 않음. 서비스 페이지에 절차를
  포함 (표현은 "개원 가이드"보다 "세부 절차"가 적절하다는 의견)
- 대표 성향: 많은 정보보다 최대한 압축 (어르신들이 읽지 않으므로)

[4) 협력사 + 포트폴리오]
- 협력사 로고는 위에서 흐르듯(마퀴) 보여주고, 아래에 포트폴리오
  (순서: 협력사 -> 포트폴리오)
- 포트폴리오는 과별로 3~5개 정도의 대표 사례 위주
  (전체 200건 이상이라 전부 올리지 않음)
- 사진은 대표의 원드라이브에서 제공. 나머지는 블로그 "더 보기"로 연결
- 상세 페이지는 홈페이지 안의 게시판(블로그형)으로 구현,
  완료 후 대표가 직접 업데이트 가능 (방법 안내 예정)
  · 블로그 연동은 사용자가 사이트를 왔다 갔다 해야 해서 비추천

[5) 상담 신청]
- 이름/연락처 + 항목 체크 방식의 문의 폼, 메일 수신
- 맨 아래 또는 별도 페이지

[6) 추후 추가 페이지]
- A/S FAQ: 정리 후 별도 페이지로 추가 (Q&A 형식, 5~10개 이상,
  많을수록 좋음). 대표가 내용을 정리해서 전달하기로 함
  · 현재 FAQ만이라도 지금 넣을지 논의했고, 정리된 후 페이지를
    추가하는 방향으로 정리
- 쇼핑몰형 견적/구매 (추후 고려)
  · 고객이 옵션을 선택하면 견적이 나오고 입금/카드결제로 연결
  · 아임웹 쇼핑몰 기능(상품 + 옵션 가격 + 결제)은 가능
  · 설문폼 -> 견적 -> 결제 연동은 아임웹 기본 기능으로는 어려움
  · 컴퓨존 가격 API 연동은 웹노바가 알아보기로 함
  · 상품은 엑셀 일괄 등록 가능. 가격은 직원이 직접 관리해야 함
  · 상품은 약 100개 규모 예상
  · 현재는 견적형으로 진행

--------------------------------------------------------------

  2. 회사 소개
  3. 서비스 소개 (차별성 + 절차)
  4. 협력사 및 포트폴리오

  - 기존에 안내한 최소안은 3페이지 구성이었으나 대표의 브랜딩 의지가
    커서 2안으로 변경

    대표는 속도보다 꼼꼼함을 원함. 연말까지만 나오면 되고,
    한 달~한 달 반도 괜찮다고 함

5. 추가 요청 (홈페이지 외)
--------------------------------------------------------------
[네이버 지도(플레이스)]
- 현재 등록이 전혀 안 되어 있음. 회사명을 검색하면 나오게 하는 것이
  목적 (광고/상위노출 목적 아님)
- 웹노바: 등록은 완벽히 가능, 상위 노출 보장은 불가

[블로그 리뉴얼]
- 로고 해상도가 낮아 보이고, 색상이 하늘색 -> 파란색으로 변경 필요
- 품목 배치/글자/이미지 변경 필요
- 인스타그램 아이콘은 없애고 홈페이지 링크로 대체
- 외주 편집자의 퀄리티에 불만이 있음 (정렬이 흐트러지고 폰트/색상
  통일이 안 됨)
- 비용: 20만 원 (웹노바 측 안내)

[브랜드북]
- 대상: 직원/협력 인력 교육용 (내부용)
  · 외부 고객용 회사소개서와는 목적이 다름
  · 회사소개서는 고객에 대한 약속, 브랜드북은 내부 구성원에게
    "회사의 비전과 성과 배분"을 전달하는 용도
- 내용: 기술이 아니라 마음가짐/철학/비전
- 분량은 간단할수록 좋음 (읽기 싫어하는 연령대)
- 기획안은 웹노바가 틀(기획 폼)을 주면 대표가 작성
- PDF로 제작. 인쇄는 별도 (인쇄용은 컬러 차이가 있을 수 있음)
- 비용: 페이지당 5만 원 (웹노바 측 안내)
- 웹노바 제안: 블로그 + 브랜드북 + 홈페이지를 모두 맡기면
  지도 등록은 서비스로 제공
  · 대표: 정가를 지불하고 싶음. 서비스 대신 "수정 횟수 무제한"을
    요청 -> 웹노바는 최소 비용만 받기로 함

6. 견적 / 계약 / 수정 범위
--------------------------------------------------------------
- 견적(대화에서 언급된 금액, 녹취상 불명확)
  · 1안: 약 126만 원 / 2안: 약 154만 원 (140만 원 언급도 있어 혼선)
  · 여기에 블로그, 브랜드북 비용이 추가됨
  · 오늘 논의 내용을 반영해 최종 견적을 다시 안내하기로 함
    (크게 달라지지 않을 것으로 예상)
  · 견적 기준: 페이지 수와 섹션 수
- 수정 횟수
  · 기본은 2회 (기획안 확정 후 디자인을 완전히 갈아엎는 수준 기준)
  · 텍스트/색상/폰트/순서/배치 변경은 횟수에서 제외
  · 예: 메인 히어로 모션을 아예 다른 구성으로 바꾸는 것은 수정 1회
  · 대표 요청: 수정 횟수 무제한 또는 그에 준하는 조건,
    "수정의 범위와 범위가 아닌 것"을 명확히 정리해서 계약서에 포함
  · 웹노바: 횟수를 정해서 비용을 소폭 올리는 방식으로 제안 가능
    -> 두 대표가 상의해 제안하기로 함
- 시안 / 환불
  · 대표는 계약 전 시안(특히 모션 그래픽)을 보고 싶어 함
  · 웹노바: 계약 -> 기획 완성 -> 메인 페이지 디자인 시안 제공.
    시안이 너무 불만족스러우면 10% 제외하고 환불 (계약서에 포함)
  · 대표: 이 조건이면 진행하겠다고 함
- 소통
  · 대표가 직접 소통. 즉시 답변은 어렵고 저녁에 정리해서 하루 1회
    정도 성의 있게 답변하는 방식
  · 간단한 수정(예: 인스타 넣고 빼기)은 방법을 알려 주기로 함
- AI 활용: 모션/홈페이지 제작에 AI를 활용한다는 점에 대표도 긍정적
  (본인도 PPT를 AI로 제작). 쇼핑몰도 AI로 구현되길 희망

8. 확인이 필요한 부분
--------------------------------------------------------------
