정확한 가이드

진료과와 병원 규모에 맞춘 품목을 제안합니다.

M-01 — 한 섹션이다(2026.10.23 사용자 지정). 데스크톱 : 화면 가득 모션그래픽 위에 제목·버튼(로드 즉시 재생, 1-1) → 스크롤하면 제목이 빠지고 같은 화면에서 장면 1~4 → 대표 카피 → M-02 가 덮으며 올라온다. 한 단계당 화면 0.8개 분량 스크롤(와이어 임시값). 아래 막대는 단계 표시이자 이동 버튼. 모바일·움직임 줄이기 : 고정하지 않고 첫 화면 → 장면 1~4 → 대표 카피를 세로로 나열(2번). 대표 카피 문구는 ⑦ 에서 확정.

카드 제목 3개는 사용자 지정(시간 절약(턴키) / 비용 절감 / 정확한 가이드). "비용 절감" 설명은 최신 조건 확인 후 기재. 데스크톱 : M-01 대표 카피가 멈춘 채로 이 섹션이 아래에서 덮고 올라온다. 덮이는 동안 앞 무대는 살짝 작아지고 어두워진다. 모바일은 일반 스크롤. 제목은 줄마다 밑에서 올라오고(I-03), 카드는 0.12초 간격으로 겹쳐 등장.
