# 핸드쉐이크 홈페이지 — 폼 항목 확인 요청

> 대표님께 확인을 받기 위한 문서입니다. (작성 2026.10.22, 웹노바)
> 아래는 **예시**입니다. 항목마다 ☐ 에 표시해 주시고, 고칠 부분은 "수정" 칸에 적어 주세요.
> - ✅ 이대로 좋음  ✏️ 수정 필요  ❌ 빼기
> - 선택지(▼)는 칸을 누르면 목록이 펼쳐지고, 그중 하나를 고르는 방식입니다(옷 사이즈 고르듯이).

## 1. A/S 접수 폼

**쓰는 사람** : 이미 핸드쉐이크와 거래 중인 병원 (로그인 후 작성)

### 1-1. 접수 전에 확인할 것

| 질문 | 대표님 답변 |
|---|---|
| 진료가 멈춘 급한 장애도 이 폼으로 받으시나요? 아니면 **"급하면 전화"** 를 폼 위에 크게 안내할까요? (폼은 메일로 들어가 확인이 늦을 수 있습니다) | |
| 로그인 계정은 **고객이 직접 회원가입**하나요, **핸드쉐이크가 만들어 드리나요?** | |
| 로그인하지 않은 사람이 A/S 페이지에 오면 어떻게 할까요? (로그인 화면으로 보냄 / 전화번호만 보여줌) | |
| 한 번 접수할 때 **품목을 여러 개** 적을 수 있어야 하나요? (예 : PC 와 복합기가 같이 고장) | |
| 접수가 들어오면 **어디로 받으시나요?** (메일 주소 / 문자 / 카카오톡) | |

### 1-2. 입력 항목

| 순서 | 항목 | 입력 방식 | 필수 | 예시 / 안내 문구 | 확인 | 수정 |
|---|---|---|---|---|---|---|
| 1 | 병원명 | 로그인 정보에서 자동으로 채움 | 필수 | ○○의원 | ☐ | |
| 2 | 담당자 이름 | 직접 입력 (로그인 정보로 미리 채움) | 필수 | 홍길동 | ☐ | |
| 3 | 연락처 | 직접 입력 (로그인 정보로 미리 채움) | 필수 | 010-0000-0000 | ☐ | |
| 4 | **품목** | 선택 ▼ | 필수 | 아래 1-3 목록 | ☐ | |
| 5 | **모델명** | 직접 입력 | 선택 | "제품 옆면이나 뒷면 스티커에 적혀 있습니다. 모르시면 비워 두셔도 됩니다" | ☐ | |
| 6 | **시리얼 넘버** | 직접 입력 | 선택 | "S/N 으로 시작하는 번호입니다. 모르시면 비워 두셔도 됩니다" | ☐ | |
| 7 | **구매 방법** | 선택 (구매 / 렌탈) | 필수 | ○ 구매  ○ 렌탈 | ☐ | |
| 8 | **증상** | 선택 ▼ (품목에 따라 목록이 바뀜) | 필수 | 아래 1-4 목록 | ☐ | |
| 9 | 증상 상세 | 직접 입력 | 증상에서 "기타"를 고르면 필수 | "언제부터, 어떤 상황에서 생기는지 적어 주세요" | ☐ | |
| 10 | **진료 영향** | 선택 | 필수 | ○ 진료를 못 하고 있음  ○ 진료는 가능함 | ☐ | |
| 11 | 사진 | 파일 첨부 | 선택 | "화면이나 장비 사진이 있으면 더 빨리 확인할 수 있습니다" | ☐ | |
| 12 | 방문 가능한 시간 | 직접 입력 | 선택 | "예 : 평일 점심시간 13~14시" | ☐ | |
| 13 | 개인정보 수집·이용 동의 | 체크 | 필수 | (법정 고지 문구 — 대표님 쪽 문구 필요) | ☐ | |

> 10번 "진료 영향"을 넣은 이유 : 진료가 멈춘 접수를 먼저 처리하기 위해서입니다(당일 A/S 기준).

### 1-3. 품목 선택지 (4번)

| 선택지 | 확인 | 수정 |
|---|---|---|
| 통신사 (인터넷·전화 개통, 회선) | ☐ | |
| 네트워크 (공유기·허브·와이파이) | ☐ | |
| PC·주변기기 (PC, 복합기, 앰프 등) | ☐ | |
| 무인경비 (경비·출입 장치) | ☐ | |
| CCTV (카메라·녹화기) | ☐ | |
| 디스플레이 (대기 화면·사이니지) | ☐ | |
| 생활가전 | ☐ | |

> **보안을 "무인경비"와 "CCTV" 둘로 나눌지, "보안" 하나로 둘지** 골라 주세요.
> 둘로 나누면 접수만 보고 어느 장비인지 바로 알 수 있습니다.  ☐ 둘로 나눔  ☐ 하나로

### 1-4. 증상 선택지 (8번) — 품목을 고르면 그 품목의 증상만 보입니다

| 품목 | 증상 선택지 (예시) | 확인 | 수정 |
|---|---|---|---|
| 통신사 | 인터넷이 안 됨 · 전화가 안 걸림/안 받아짐 · 전화 설정 변경(돌려받기·컬러링 등) · 기타 | ☐ | |
| 네트워크 | 인터넷이 자주 끊김 · 인터넷이 느림 · 와이파이가 안 잡힘 · 기타 | ☐ | |
| PC·주변기기 | 전원이 안 켜짐 · 느림/멈춤 · 프로그램 오류 · 인쇄·스캔이 안 됨 · 모니터·대기 화면 연결 안 됨 · 스피커(앰프) 소리 안 남 · 기타 | ☐ | |
| 무인경비 | 경보가 잘못 울림 · 출입 인식이 안 됨(카드·지문) · 근태 기록 오류 · 기타 | ☐ | |
| CCTV | 화면이 안 나옴 · 녹화가 안 됨 · 휴대폰으로 안 보임 · 기타 | ☐ | |
| 디스플레이 | 화면이 안 나옴 · 내용이 안 바뀜 · 기타 | ☐ | |
| 생활가전 | 작동이 안 됨 · 물이 샘 · 소음 · 기타 | ☐ | |

> 증상 목록은 **예시**입니다. 실제로 자주 들어오는 A/S 를 기준으로 고쳐 주세요.
> 모든 품목에 **"기타"** 가 있고, 기타를 고르면 9번 "증상 상세"를 꼭 적게 됩니다.

## 2. 상담 신청 폼

**쓰는 사람** : 처음 문의하는 원장님, 또는 원장님을 소개해 주는 업체 (로그인 없이 작성)

### 2-1. 접수 전에 확인할 것

| 질문 | 대표님 답변 |
|---|---|
| 상담 신청이 들어오면 **어디로 받으시나요?** (메일 주소 / 문자 / 카카오톡) | |
| 홈페이지 폼은 **간단하게**(연락받을 정보 + 필요한 품목) 받고, 자세한 내용은 나중에 보내시는 **상담양식**으로 받을까요? 아니면 홈페이지 폼에서 자세히 받을까요? | |
| 인테리어·프랜차이즈·컨설팅 **업체가 문의할 때**도 같은 폼을 쓸까요? | |

### 2-2. 입력 항목

| 순서 | 항목 | 입력 방식 | 필수 | 예시 / 안내 문구 | 확인 | 수정 |
|---|---|---|---|---|---|---|
| 1 | 문의하시는 분 | 선택 | 필수 | ○ 원장님(병원)  ○ 인테리어·프랜차이즈·컨설팅 업체 | ☐ | |
| 2 | 이름 | 직접 입력 | 필수 | 홍길동 | ☐ | |
| 3 | 연락처 | 직접 입력 | 필수 | 010-0000-0000 | ☐ | |
| 4 | 병원명(또는 업체명) | 직접 입력 | 선택 | "개원 전이면 비워 두셔도 됩니다" | ☐ | |
| 5 | 진료과 | 선택 ▼ | 선택 | 아래 2-3 목록 | ☐ | |
| 6 | 병원 지역 | 직접 입력 | 선택 | "예 : 서울 강남구" | ☐ | |
| 7 | 평수 | 직접 입력 | 선택 | "예 : 50평" | ☐ | |
| 8 | 개원(이전) 예정일 | 날짜 선택 | 선택 | "대략적인 달만 적어 주셔도 됩니다" | ☐ | |
| 9 | 상황 | 선택 | 선택 | ○ 신규 개원  ○ 확장·이전  ○ 개원 후 추가 구매 | ☐ | |
| 10 | 필요한 품목 | 여러 개 선택(체크) | 선택 | 1-3 과 같은 7개 품목 + "아직 모르겠어요" | ☐ | |
| 11 | 인테리어 업체 | 선택 | 선택 | ○ 정해짐  ○ 아직 안 정해짐 | ☐ | |
| 12 | 문의 내용 | 직접 입력 | 선택 | "궁금하신 점을 자유롭게 적어 주세요" | ☐ | |
| 13 | 연락받기 편한 시간 | 직접 입력 | 선택 | "예 : 평일 오후 6시 이후" | ☐ | |
| 14 | 개인정보 수집·이용 동의 | 체크 | 필수 | (법정 고지 문구 — 대표님 쪽 문구 필요) | ☐ | |

> 9번 "상황"을 넣은 이유 : 대표님 질문지에 고객이 **개원 준비 / 확장·이전 / 개원 후 추가 구매** 세 갈래로 나와 있어서입니다.
> 가격을 묻는 칸은 넣지 않았습니다(가격은 상담에서 안내).
