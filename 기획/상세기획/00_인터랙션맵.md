## 1. 레퍼런스에서 확인한 것

**확인 방법** (2026.10.23) : 컨테이너 네트워크 정책이 세 사이트를 막아(프록시 403) 직접 브라우저로는 못 열었다.
Firecrawl 로 **1440px 전체 화면 캡처 + 렌더된 HTML** 을 받아 구조·라이브러리를 읽었다.
→ **"확인"** = HTML·캡처에서 직접 본 것 / **"추정"** = 구조로 미루어 본 것(실제 스크롤 속도·이징은 못 봤다)

|---|---|---|---|
| 카누 리미티드 에디션 | 어두운 바탕, 화면 한가운데 짧은 글, **영화처럼 한 장면씩** 넘어간다 | Next.js · **Lenis**(부드러운 스크롤) · GSAP ScrollTrigger(`pin-spacer` 다수) · Swiper | ① 첫 화면 300vh 고정 — 큰 사진이 확대된 채 시작해 줄어들고, 원두 사진 10여 장이 사방으로 흩어진다(추정) ② **한 고정 무대 안에서 장면 3개가 겹쳐 바뀐다**(z-10/20/40 섹션이 같은 자리에 겹쳐 있음 — 확인) ③ 가운데 상자가 커지며 화면을 채운다(`will-change:width,height` — 확인) ④ 240px 초대형 글자가 **한 글자씩** 나타난다(`data-fifth-pin-char` — 확인) ⑤ 공정 카드가 고정된 채 옆으로 넘어간다 ⑥ 산지·프로세스 비교표에 선이 그어진다(`data-origin-line` — 확인) |

**세 곳의 공통점 — 사용자가 원하는 "느낌"을 이렇게 읽었다**
1. **스크롤 자체가 부드럽다**(세 곳 다 Lenis) — 휠 한 번에 툭 떨어지지 않고 미끄러진다
2. **페이지마다 "큰 장면" 한두 개**만 있고 나머지는 조용하다 — 모든 섹션이 움직이지 않는다
3. 글은 **짧고 크고**, 사진은 **넓다**. 움직임은 사진·장면 쪽이 맡고 글은 줄 단위로 단정하게 올라온다
4. 장식(글로우·그라데이션·아이콘 남발)이 거의 없다 — CLAUDE.md 5번과 방향이 같다

## 4. 사용자가 고를 것

**A. I-10 부드러운 스크롤(Lenis)을 쓸까** — 세 레퍼런스 느낌의 절반이 이것이다
- 쓴다 : 레퍼런스와 가장 비슷해진다. 대신 아임웹 자체 스크롤 기능(맨 위로·앵커 이동·팝업)과 부딪히는지 ⑧ 단계에서 실제 주소로 확인해야 하고, 데스크톱만 켠다
- 안 쓴다 : 브라우저 기본 스크롤. 안전하지만 "미끄러지는 느낌"은 없다

**B. M-03 서비스 요약 배치**
- B1(현재 확정안) : 카드 3열 + 순차 등장
- B2 : **I-06 목록 + 바뀌는 사진** — 왼쪽 서비스 5개 목록, 오른쪽 큰 사진. 배치가 바뀌므로 01_메인.md 를 고친다

**C. 푸터 초대형 워드마크** — 넣는다 / 안 넣는다 (푸터를 코드 위젯으로 만들 때만 가능)

**D. 안 쓰기로 한 것** (이의 있으면 말해 달라)
- 로딩 화면 · 페이지 전환 연출 — 내용을 늦게 보여준다(대표님 "최대한 압축"과 반대). 아임웹은 페이지마다 새로 불러와서 전환 연출도 어렵다
- 마우스 커서 바꾸기·끌기 커서 — 어르신 사용자에게 헷갈리고 터치에선 의미 없다
- 유리 굴절 캔버스(메이커빌) · 흩어지는 사진 수십 장(카누) — 무겁고(3번), 우리 소재(통신·보안·가전)에 옮기면 어색하다
- 한 글자씩 등장(카누 ④) — 한글은 받침 때문에 글자 단위로 끊으면 어색하고, 줄 단위(I-03)로 충분하다
