### G-03. 버튼

| 종류 | 생김(디자인에서 결정) | 쓰는 곳 | 문구 [가안] |
|---|---|---|---|
| 주 버튼 | 가장 눈에 띄는 버튼. **한 화면에 하나** | 상담으로 보낼 때 | 상담 신청 |
| 보조 버튼 | 주 버튼보다 약하게 | 페이지 이동 | 서비스 자세히 보기 · 포트폴리오 전체 보기 |
| 전화 버튼 | 주/보조 중 디자인에서 결정 | A/S · 모바일 | 전화하기 |
| 텍스트 링크 | 글자 + → | 섹션 안 작은 이동 | 회사 소개 보기 → |
| 폼 제출 | 주 버튼 | 폼 맨 아래 | 상담 신청하기 · A/S 접수하기 |

- 버튼 문구는 **동사로 끝나는 짧은 말**. "자세히", "더보기"만 단독으로 쓰지 않는다(무엇을 보는지 붙인다)
- 모든 버튼 터치 영역 44px 이상(CLAUDE.md 2-A · 8번), 키보드 포커스 표시(8번)

### G-04. 카드
- 구성 : (아이콘 또는 사진) + 제목 + 설명 1~2줄. 링크가 있으면 **카드 전체**를 누를 수 있게
- 아이콘은 **선 아이콘 한 세트**, 제목 **왼쪽**에(5-2 #8). 이모지 금지(#9)
- 왼쪽 컬러 띠 금지(5-3 #16), 모서리 12~16px(#19), 테두리와 그림자는 둘 중 하나(#20)
- 같은 줄 카드는 설명 길이가 달라도 **높이를 맞춘다**

### G-05. 폼 공통 규칙 (R-02 · C-02)
- 필수 항목은 이름 옆 **`*`** 표시, 폼 위에 "* 표시는 꼭 입력해 주세요" 한 줄 [가안]
- 오류 문구 [가안] — 칸 바로 아래 한 줄로

  | 상황 | 문구 |
  |---|---|
  | 필수 칸 비움 | ○○을(를) 입력해 주세요 |
  | 연락처 형식 | 연락처를 다시 확인해 주세요 (예 : 010-0000-0000) |
  | 선택 안 함 | ○○을(를) 선택해 주세요 |
  | 증상 "기타" + 상세 비움 | 증상을 자세히 적어 주세요 |
  | 개인정보 동의 안 함 | 개인정보 수집·이용에 동의해 주세요 |

- 제출 후 **완료 화면** 문구 [대기 — 대표님 : 몇 시간 안에 연락하는지]
  - 상담 [가안] : "상담 신청이 접수되었습니다. 확인 후 연락드리겠습니다."
  - A/S [가안] : "A/S 접수가 완료되었습니다. 진료가 멈춘 급한 장애는 전화로 연락 주세요. [전화하기]"
- 선택지 목록(품목·증상·진료과)은 G-01 · `고객확인_폼항목.md` 를 따른다
- 아임웹 기본 폼이면 우리 CSS 가 안 걸린다(1-4) — 글자 크기·줄바꿈은 전역 CSS 로 맞춘다

### G-06. 이미지 자리
- 자리마다 **비율을 고정**한다(사진 크기가 달라도 칸이 흔들리지 않게). 비율은 와이어에서 정한다
- 사진이 없거나 깨지면 **이름만 든 빈 박스**로 대체 — 레이아웃 유지
- 와이어에서는 X 박스 + "필요 자료 이름"

### G-07. 마지막 섹션의 [상담 신청] 버튼 [확정 — 2026.10.22]
- 회사 소개 **A-03**, 서비스 **S-05**, 포트폴리오 **P-02** — 각 페이지 **마지막 섹션 안 맨 아래**에 [상담 신청] 버튼(주 버튼, G-03) 하나
- 별도 띠 섹션을 만들지 않는다 — 섹션 수 그대로
- 버튼 위 한 줄 문구를 둘지는 ⑥ 상세 기획에서 페이지마다 정한다 [가안 : 없음 — 버튼만]
- 메인은 M-06 상담 CTA 가 이 역할, A/S·상담 신청 페이지는 해당 없음

### G-08. 모바일 하단 고정 바 [확정 — 2026.10.22]
- 768px 이하 모든 페이지 화면 맨 아래에 항상 떠 있다 : **[전화하기] [상담 신청]** 두 버튼, 반반 나눔
- [전화하기] : 누르면 바로 전화(번호는 G-02). [상담 신청] : `/contact` 로 이동
- **상담 신청 페이지(`/contact`)에서는 [전화하기] 만** 보인다(바 전체 폭) [확정 — 2026.10.22]
- 푸터 맨 아래와 폼 제출 버튼이 바에 **가리지 않게** 바 높이만큼 아래 여백을 둔다
- 데스크톱에는 없다(헤더 [상담 신청] 이 그 역할)
- 구현 주의 : 화면 높이(`vh`)에 기대지 않는 고정 배치(CLAUDE.md 2번 — 주소창이 접힐 때 흔들리지 않게), 터치 영역 44px(8번)

### G-10. 레이아웃 그리드 [확정 — 2026.10.22 상세 기획]
- 콘텐츠 최대 폭 **1200px**, 가운데. 좌우 여백 **40px**(데스크톱) / **20px**(모바일 ≤768px)
- 데스크톱 **12열**, 열 간격 **24px** — 각 섹션 배치는 "몇 열 ~ 몇 열"로 적는다
- 모바일은 기본 **1열**. 2열이 필요한 곳(포트폴리오 사진 등)만 섹션에 따로 적는다
- 섹션 위아래 여백 **96px / 56px**, 섹션 제목 묶음 아래 **40px / 28px**
- 섹션 배경은 **기본 / 구분 배경을 번갈아** 쓴다(색은 디자인에서)
- 화면 높이에 맞추는 섹션(메인 히어로)만 예외 — 높이 규칙은 그 섹션에 적는다
