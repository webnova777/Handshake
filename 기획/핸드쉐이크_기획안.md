- 4-2. 회사 소개 (`A-`, **1~3섹션**) — 미션·목적·가치·강점

- 4-5. A/S 접수 (`R-`, **1~3섹션**) — 2026.10.22 추가. 접수 폼·응대 기준(당일 A/S, 영업시간) 등

#### M-01. 히어로 + 일하는 과정 모션그래픽

- **목적** : 첫 화면에서 회사 정체를 한 문장으로 밝히고, 스크롤하면 "상담 → … → 사후관리"까지
  **한 업체가 처음부터 끝까지 맡는 흐름**을 장면으로 보여준다. 메인에서 가장 중요한 섹션(미팅).
- **구성** — 두 단계로 나뉜다
  1. **첫 화면(히어로)** : 브랜드 + 헤드라인 + 리드 + 버튼
  2. **스크롤 장면(모션그래픽)** : 히어로 아래로 스크롤하면 장면이 차례로 바뀐다
- **문구**

  | 자리 | 문구 | 상태 | 출처 |
  |---|---|---|---|
  | 라벨(eyebrow) | 병원 통신·보안·가전 솔루션 | [가안] | 소개서 표지 |
  | 헤드라인 h1 | 편리하게 납품하고 / 신속하게 지킵니다 | [가안] | 소개서 표지 |
  | 리드 | 병원 진료를 지키기 위해, 계약부터 설치, 개원 후 A/S까지 핸드쉐이크가 책임집니다. | [가안] | 소개서 표지 |
  | 버튼 1 (주) | 상담 신청 | [가안] | |
  | 버튼 2 (보조) | 일하는 과정 보기 ↓ (스크롤 장면으로 내려감) | [가안] | |

  - 소개서 표지 문구 "통신·보안·가전, 편리하게 납품하고 신속하게 지킵니다"를 **라벨과 h1 로 나눴다.**
    통째로 h1 에 넣으면 모바일(h1 32px, 쓸 수 있는 폭 약 335px)에서 **3줄**이 될 가능성이 높다 —
    CLAUDE.md 5-2 #10(폰에서 두 줄 안). 줄 수는 와이어프레임에서 실측해 확정한다.
- **스크롤 장면** — **[대기] 대표님 커트 정리**(미팅 액션 아이템). 아래는 기획 기준안

  | 장면 | 내용 | 키워드 | 출처 |
  |---|---|---|---|
  | 1. 문의 | 상담 · 설계 · 조율 · 계약 — 진료과·규모에 맞춘 품목 구성 | 신뢰 | 질문지 3번 |
  | 2. 납기 전 사전작업 | 인테리어 공정표·도면 공유, 번호 채번, 기기 제원 송부 | 편리 | 질문지 3번 · 소개서 |
  | 3. 납품·설치 | 네트워크 → 통신사 개통 → PC·전화 셋팅을 **한 일정표로** | 편리 | 소개서 7쪽 |
  | 4. 납품 후 A/S | CS관리방, 진료 불가 시 당일 A/S, 원격 확인 | 신속 | 질문지 · 미팅 |

  - 미팅에서는 "상담 → 견적 → 계약 → 품목별 설치 → 사후관리"(5단계)로 말했고, 질문지는 위 4단계다.
    **둘 중 무엇으로 갈지 대표님 확인 필요** — 기준안은 브랜드 키워드(신뢰·편리·신속)와 1:1 로 맞는 4단계.
  - 표현 방식(캐릭터 / 인포그래픽 / 실사·AI 이미지)도 미정(미팅). 와이어에서는 장면마다 회색 박스 + 장면 설명.
- **필요 자료** : 장면 구성(대표님), 로고 원본(벡터), 장면 이미지 또는 일러스트 방향(미정)
- **레이아웃**
  - 데스크톱 : 히어로는 첫 화면을 채운다(헤더 겹침, 1-5). 장면은 화면에 고정된 채 스크롤에 따라 교체
  - 모바일(≤768px) : 같은 순서. 장면은 **세로로 쌓아도 이해되게** — 고정·교체가 어려우면 차례로 나열
- **동작**
  - 히어로 : 로드와 동시에 등장(스크롤 감지 없음). 속도는 `프로젝트사양.md` 6번 — 히어로 진입값은 [대기]
  - 장면 : 스크롤 위치에 따라 교체. 장면 사이 **겹쳐 전환**(4번 "순차가 아니라 겹치기")
  - 움직임 줄이기 설정 사용자 : 장면을 정지 이미지 4장으로 나열
- **예외**
  - 장면 자료가 늦으면 : 히어로만 먼저 완성하고 장면 구간은 정지 4단계 카드로 대체 가능하게 설계
  - JS 꺼짐 : 장면 전부 펼친 상태로 보인다(1-2 — `@media (scripting:none)`)
- **구현 주의** : 1-1(히어로는 CSS 애니메이션, 숨김을 JS 로 걸지 않기) · 1-5(헤더 투명 겹치기, 그리드 해제) ·
  2번(고정 구간 높이를 `vh`·`innerHeight` 에 걸지 않기, `ignoreMobileResize`) · 3번(화면 밖이면 멈춤) ·
  3-A(글자 확대 연출이면 크게 그려 줄이기) · 1-3(영상이면 외부 CDN)
- **와이어** : `기획/와이어프레임/main.html#M-01` (작성 예정)
