## 0. 이 문서 읽는 법

- 섹션 ID 규칙 : 페이지 머리글자 + 번호 — 메인 `M-01`, 회사 소개 `A-01`, 서비스 `S-01`,
  협력사·포트폴리오 `P-01`, 상담 신청 `C-01`, 공통 `G-01`. 와이어프레임의 같은 ID 와 1:1
- 문구 표시 : **[확정]** 대표님 확인 끝 / **[가안]** 우리가 쓴 초안 / **[대기]** 자료·답변 대기
- 와이어프레임 : `기획/와이어프레임/` (페이지당 HTML 한 파일, 768px 전환)

## 1. 프로젝트 개요
- 1-1. 목적 — 신뢰도 향상 + 소구점(궁금증·불안)을 미팅 전에 해소 → "소구된 상태로 문의"
- 1-2. 타깃 — ① 직접 구매하는 원장님(개원·확장·이전·추가 구매) ② 소개해 주는 거래처(인테리어·프랜차이즈·컨설팅)
- 1-3. 브랜드 키워드·톤 — 신뢰·신속·편리 / 신뢰감 있고 전문적
- 1-4. 성공 기준 — 방문자 수보다 전환율·이해도
- 1-5. 하지 않는 것 — 가격 공개, 개원 가이드 페이지, (이번 범위) 쇼핑몰

## 2. 디자인·구현 사양 요약
- `프로젝트사양.md` 의 확정값을 표로 옮겨 싣는다(타이포 크기·토큰, 768px, 속도, 접두어, 서체, 컬러)

## 3. 사이트 구조
- 3-1. 사이트맵 (5페이지 + 추후 2)
- 3-2. 헤더·GNB (데스크톱 / 모바일 메뉴)
- 3-3. 푸터 (회사 정보·연락처·영업시간·블로그·지도 링크)
- 3-4. 상담 진입 경로 (어느 페이지에서든 상담 신청까지 몇 번 만에 가는지)

## 4. 페이지별 기획

각 섹션은 같은 틀로 쓴다 :
`ID · 목적 · 문구 · 필요 자료(누가 줌) · 레이아웃(데스크톱/모바일) · 동작·모션 · 예외 상황 · 구현 주의(지침 번호) · 와이어 링크`

- 4-1. 메인 (`M-`) — 스크롤 모션그래픽(상담 → 견적 → 계약 → 품목별 설치 → 사후관리), 서비스·차별점 요약, 협력사 로고, 문의
- 4-2. 회사 소개 (`A-`) — 미션·목적·가치·강점, 문의
- 4-3. 서비스 소개 (`S-`) — 통신·보안·가전 품목별 차별점 + 세부 절차
- 4-4. 협력사·포트폴리오 (`P-`) — 협력사 로고(마퀴) → 진료과별 대표 사례 3~5건, 상세는 게시판, 블로그 "더 보기"
- 4-5. 상담 신청 (`C-`) — 이름·연락처 + 항목 체크 폼, 메일 수신
